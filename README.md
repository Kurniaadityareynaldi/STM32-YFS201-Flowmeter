# STM32 YF-S201 Water Flow Meter Library

A C library for reading the **YF-S201 water flow sensor** using an **STM32 (HAL) + external interrupt (EXTI)**. It calculates **flow rate (L/min)** and **total volume (Liters)** in a *non-blocking* way (no `HAL_Delay`).

> Written for STM32F103 (Blue Pill) with STM32CubeIDE.

## Features

- Sensor pulse counting via EXTI interrupt
- Flow rate in **L/min**
- Total volume in **Liters** (cumulative) and total pulse count
- Non-blocking: calculated periodically by `Flowmeter_Update()` using `HAL_GetTick()`
- Adjustable calibration factor and sampling interval
- Supports multiple sensors (each sensor has its own handle)

## Hardware

| YF-S201        | STM32F103 (Blue Pill) |
|----------------|-----------------------|
| Red (VCC)      | 5V                    |
| Black (GND)    | GND                   |
| Yellow (Signal)| PA0 (EXTI0)           |

> ⚠️ The sensor output can reach 5V when the sensor is powered from 5V. Check the MCU datasheet to confirm the pin you use is *5V tolerant*, or use a **voltage divider / level shifter** down to 3.3V.

Pulse indicator LED: **PC13** (onboard Blue Pill LED).

## STM32CubeMX Configuration

1. **PA0** → `GPIO_EXTI0`
2. **GPIO mode**: `External Interrupt Mode with Rising edge trigger detection`
3. **Pull-up**: `Pull-up`
4. **NVIC**: enable `EXTI line0 interrupt`
5. Clock: HSE + PLL x9 = 72 MHz

> Note: `TIM2` may be generated in this project, but the library **does not use it**. TIM2_CH1 is also on PA0, so it is best to disable `TIM2` in CubeMX to avoid conflicting with EXTI.

## Usage

**1. Copy the files:** `flowmeter.h` to `Core/Inc/` and `flowmeter.c` to `Core/Src/`.

**2. In `main.c`:**

```c
/* USER CODE BEGIN Includes */
#include "flowmeter.h"
/* USER CODE END Includes */

/* USER CODE BEGIN 0 */
Flowmeter_HandleTypeDef hflow;
float flowrate = 0;      // L/min
float total_volume = 0;  // Liters

void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    Flowmeter_PulseCallback(&hflow, GPIO_Pin);
}
/* USER CODE END 0 */

int main(void)
{
    ...
    /* USER CODE BEGIN 2 */
    Flowmeter_Init(&hflow, GPIOA, GPIO_PIN_0, EXTI0_IRQn, 7.5f, 1000);
    Flowmeter_Start(&hflow);
    /* USER CODE END 2 */

    while (1)
    {
        /* USER CODE BEGIN 3 */
        if (Flowmeter_Update(&hflow))
        {
            flowrate     = Flowmeter_GetFlowRate(&hflow);
            total_volume = Flowmeter_GetTotalVolume(&hflow);
        }
    }
}
```

**3.** Run in *Debug* mode and watch `flowrate` and `total_volume` in **Live Expressions**.

## API

| Function | Description |
|----------|-------------|
| `Flowmeter_Init(h, port, pin, irq, calibration, interval_ms)` | Initialize the handle |
| `Flowmeter_Start(h)` | Start measuring (enables EXTI) |
| `Flowmeter_Stop(h)` | Stop measuring |
| `Flowmeter_PulseCallback(h, GPIO_Pin)` | Call from `HAL_GPIO_EXTI_Callback()` |
| `Flowmeter_Update(h)` | Periodic calculation, returns `1` when new data is ready |
| `Flowmeter_GetFlowRate(h)` | Flow rate (L/min) |
| `Flowmeter_GetTotalVolume(h)` | Total volume (Liters) |
| `Flowmeter_GetTotalPulses(h)` | Total pulse count |
| `Flowmeter_ResetTotal(h)` | Reset total volume and pulse count |

## Formulas

YF-S201 specification: `F (Hz) = 7.5 × Q (L/min)`

```
Frequency (Hz) = pulses / time (s)
Flow rate      = Frequency / 7.5                    [L/min]
Volume         = pulses / (7.5 × 60) = pulses / 450 [Liters]
```

Example: 75 pulses in 1 second → 75 Hz → **10 L/min**.

### Calibration

7.5 is a typical value. For better accuracy, run **1 liter** of water through the sensor and record the pulse count (`total_pulses`):

```
calibration = pulses_per_liter / 60
```

Example: 420 pulses/liter → `calibration = 7.0`.
